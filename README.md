# The Nexus — Windows downloads

The Nexus **1.2.0 Alpha**, build **1.2.0.0**, is available for Windows x64.

[**Download Windows Setup**](https://github.com/N7-Spectres/the-nexus-downloads/releases/download/v1.2.0-alpha/The-Nexus-1.2.0.0-Alpha-Setup-x64.exe) · [Release notes and tested limits](https://github.com/N7-Spectres/the-nexus-downloads/releases/tag/v1.2.0-alpha)

An updated interface, easier settings and a cleaner Memory screen, with guided ElevenLabs setup for speaking saved replies using your own account. Each new voice generation requires approval and uses your provider allowance. Phone connections and Talk/transcription are not included.

Close Nexus before running Setup, then open The Nexus from Start. First-time users and portable 1.0 users should use Setup. Existing managed installations can use Settings → Updates to download and apply verified updates. Do not extract the Update ZIP over an installation.

New-profile setup requests local automatic Memory and relevant recall when the required tools and connection are ready. Existing choices and restore pauses are preserved. Automatic Memory may miss details; review important notes and use manual notes when needed. Recovery exports are manual. Make one before upgrading important data.

The real signed 1.1.0.12 → 1.2.0.0 update, automatic reopen, normal Start-menu reopen and fictional saved-data retention passed in the dedicated Windows test VM. Real speech-provider availability and audio playback remain unverified. This is a Windows alpha, not a guarantee for every PC; see the release notes for remaining limits.

The installer is unsigned by Microsoft. Follow Windows security guidance. Nexus's in-app publisher-signature verification is separate from Microsoft code signing.

Use the final documentation linked in the release description. Earlier validation-stage files and the previous 1.1.0 release remain available as historical records.
