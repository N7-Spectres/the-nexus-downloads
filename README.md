# The Nexus — Windows downloads

Official app downloads and update information for The Nexus.

## Downloads

Public downloads will appear on the [Releases page](https://github.com/N7-Spectres/the-nexus-downloads/releases) after testing and release review are complete.

No app release is available from this public channel yet. Nexus 1.1.0 and its in-app update feature are in preparation.

## About this repository

This repository is for released app files, release notes and update information. The development project and its history are not published here.

Windows x64 is the current desktop target. Phone support is not included in the planned Windows release.

## Reporting a problem

Describe the app version and the steps that caused the problem. Keep API keys, account identifiers, recovery files, passphrases and private conversations out of public reports.
