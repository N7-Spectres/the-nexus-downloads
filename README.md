# The Nexus — Windows downloads

The Nexus 1.1.0 Alpha for Windows x64 is available as **build 1.1.0.12**.

[**Download Windows Setup**](https://github.com/N7-Spectres/the-nexus-downloads/releases/download/v1.1.0-alpha/The-Nexus-1.1.0.12-Alpha-Setup-x64.exe) · [Release notes and tested limits](https://github.com/N7-Spectres/the-nexus-downloads/releases/tag/v1.1.0-alpha)

Close Nexus, run Setup, then open The Nexus from Start. First-time users and portable 1.0 users should use Setup. Existing managed installations can use Settings → Updates to download and apply verified updates. Do not extract the Update ZIP over an installation.

Optional local automatic Memory reviews new chats only after you enable it. It can miss details or choose broad categories; manual notes remain available. Recovery exports are manual. Make one before upgrading important data.

This is an unsigned Windows alpha. Follow your Windows security policy. In-app publisher-signature verification is separate from Microsoft code signing. Phone support is not included. See the release notes for the tested VM matrix and remaining unverified branches.

Use the uniquely named build 12 files linked in the release description. Older builds and unversioned attachments are retained as historical test evidence.

## About this repository

This repository contains public app downloads, release notes and update information. Application development source and history remain private. GitHub's generated source archives contain this downloads repository only.

## Reporting a problem

Describe the app version and the steps that caused the problem. Keep API keys, account identifiers, recovery files, passphrases and private conversations out of public reports.
